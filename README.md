# Northline Atelier

Fikcyjne studio tuningowe — strona demonstracyjna oparta na montażu wideo (React, Vite, TypeScript, GSAP + ScrollTrigger, Lenis, SCSS).

## Uruchomienie

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc + vite build -> dist/
npm run preview    # podgląd builda
npm run video:split  # ponowne pocięcie Honda_NSX_white_final.mp4 (FFmpeg z ffmpeg-static)
```

Wynik `npm run build` (`dist/`) to statyczna strona gotowa do wdrożenia na dowolny hosting.
